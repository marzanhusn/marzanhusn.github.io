# Marzan Husain – Personal Portfolio

Fully responsive single-page portfolio built with **semantic HTML5 + vanilla CSS only**.

- No JavaScript  
- No CSS frameworks  
- No external libraries / no Google Fonts  

## Theme
Sleek developer-friendly **light blue** palette with clear visual hierarchy and balanced spacing.

## Structure
```
marzan-portfolio-final/
├── index.html
├── style.css
├── assets/          ← put profile photo here (optional)
└── README.md
```

## Sections
1. Hero / Header  
2. About Me  
3. Skills & Expertise (3 cards)  
4. Projects & Experience  
5. Contact  
6. Footer  

## How to use
1. Update Email, GitHub, and LinkedIn links in `index.html`
2. Open `index.html` in any browser
3. Push to GitHub and enable **GitHub Pages**
